# Support

- Usage questions and ideas: [GitHub Discussions](https://github.com/GofMan5/secure-software/discussions)
- Confirmed bugs: [GitHub Issues](https://github.com/GofMan5/secure-software/issues)
- Sensitive security reports: [private vulnerability reporting](https://github.com/GofMan5/secure-software/security/advisories/new)

Include your Codex surface, plugin version, operating system, exact command or prompt, and sanitized output. Never post credentials, private source code, customer data, or production secrets in a public issue.
