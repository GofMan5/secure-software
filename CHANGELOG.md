# Changelog

All notable changes follow [Semantic Versioning](https://semver.org/).

## 1.2.0 - 2026-07-24

- Added the stdlib-only ChainBench-12 blind A/B runner with six vulnerable/near-miss pairs, reproducible randomization, frozen execution-context receipts, process-tree deadlines, mutation checks, and deterministic evidence metrics.
- Added scanner, binary/decompiler, and runtime evidence adapters with bounded subprocesses, normalized receipts, redaction, and offline self-tests.
- Added a cross-language software-protection runbook for stable release hardening, obfuscation, packing/virtualization, anti-tamper, licensing, signing, and measured reverse-resistance checks.
- Integrated evidence collection and benchmark validation into the skill, repository gate, and public documentation.

## 1.1.0 - 2026-07-24

- Made offensive testing, reverse engineering, exploit and payload execution, fuzzing, scanning, credential auditing, persistence simulation, and adversary emulation first-class skill outcomes.
- Treated a named target and action as the execution contract and kept unresolved external work operational through placeholders and disposable fixtures.
- Replaced blanket authorization blockers in platform and intelligence guidance with explicit target, effect, cleanup, rollback, and physical-safety bounds.
- Updated skill metadata, public documentation, and the desktop reverse-engineering regression case for working exploit proof behavior.
- Made release ZIPs byte-for-byte deterministic across Windows and Linux by sorting POSIX names, pinning metadata, and avoiding zlib-version variance.

## 1.0.0 - 2026-07-24

- Initial public skills-only Codex plugin release.
- Added adversarial audit, threat-model, reverse-engineering, validation, attack-path, and root-remediation workflows.
- Added web, API, desktop, mobile, cloud/IAM, CI/CD, OS, container, game, firmware, IoT, and OT/ICS coverage.
- Added provenance-rich MITRE ATT&CK and CISA KEV snapshot tooling with strict integrity, freshness, and resource checks.
- Added Codex Security executor routing and Ponytail full compatibility.
- Added marketplace packaging, public documentation, evaluation materials, CI validation, and dual MIT/Apache-2.0 licensing.
