# Privacy Policy

Effective date: 2026-07-24

Secure Software is a skills-only, open-source Codex plugin. The project maintainer does not operate a backend service, user account system, analytics service, or telemetry endpoint for this plugin and does not receive the repositories, prompts, reports, or threat-intelligence snapshots processed in your Codex environment.

The bundled threat-intelligence fetcher makes HTTPS requests to public MITRE ATT&CK data hosted on GitHub and to the CISA Known Exploited Vulnerabilities feed when you run it. Those providers receive ordinary network metadata such as your IP address and user agent under their own privacy policies. The resulting snapshot is written only to the output location you choose.

Codex, GitHub, operating-system tools, security scanners, MCP servers, browsers, cloud providers, and other services you use with the skill process data under their own terms and privacy policies. Review their configuration before sharing proprietary code, personal data, credentials, or production evidence.

Public GitHub contributions, issues, and discussions are visible according to GitHub's policies. Use private vulnerability reporting for sensitive security information.

Questions may be opened through [GitHub Discussions](https://github.com/GofMan5/secure-software/discussions).
