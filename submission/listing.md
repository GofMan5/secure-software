## Long description

Secure Software helps Codex threat-model, audit, reverse, validate, and harden websites, APIs, services, desktop and mobile apps, cloud and IAM, CI/CD, containers, operating systems, dependencies, update chains, games, firmware, IoT, and OT/ICS.

It prioritizes realistic, reachable attack chains over checklist volume. Candidates move through explicit discovery, validation, attack-path, and remediation phases. Reportable findings include exact evidence, attacker prerequisites, complete source-to-impact reasoning, counterevidence, blast radius, confidence, and the smallest complete root-boundary fix.

The plugin can use installed Codex Security executors for repository and diff scans while preserving an adversarial evidence contract. It also includes a provenance-rich standard-library fetcher for active MITRE ATT&CK Enterprise, Mobile, and ICS techniques and the CISA Known Exploited Vulnerabilities catalog.

## Starter prompts

1. Threat-model this repository and trace the highest-impact attack paths.
2. Run a deep security audit and validate findings from entry point to impact.
3. Fix the validated finding at the narrowest shared trust boundary.
